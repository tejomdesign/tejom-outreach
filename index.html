🔑 API Keys & Connection

💡 All fields are saved in your browser. You only need to fill these once.

🔑 Step 1 — Get Google API Key (Free)

1

Go to console.cloud.google.com → sign in with your Gmail

2

Click Select a Project → New Project → name it tejom-search → Create

3

Click APIs & Services → Library → search Custom Search API → Click it → Click Enable

4

Go to APIs & Services → Credentials → + Create Credentials → API Key

5

Copy the key → paste it in Google API Key field above

🔵 Step 2 — Get Search Engine ID (Free)

1

Go to cse.google.com (Programmable Search Engine)

2

Click Add → In "Sites to search" type *.com → Give it any name like tejom

3

Click Create → then click Customize

4

Turn ON "Search the entire web" toggle

5

Copy the Search Engine ID → paste in Google Search Engine ID field above

📜 Step 3 — Google Apps Script

Paste this in your Google Sheet → Extensions → Apps Script

🌐 Step 4 — Deploy Apps Script as Web App

1

In Apps Script → click Deploy → New Deployment

2

Click ⚙️ gear → select Web App

3

Execute as: Me | Who has access: Anyone → Click Deploy

4

Authorize → Copy the Web App URL → paste above → Save All

🌐 Step 5 — Host Free on GitHub Pages

1

Go to github.com → Sign up free

2

Click + New Repository → name: tejom-outreach → Public → Create

3

Click Add file → Create new file → name it index.html → paste this site's full code

4

Click Commit changes → Go to Settings → Pages → main → Save

5

Live at: https://YOUR-USERNAME.github.io/tejom-outreach
